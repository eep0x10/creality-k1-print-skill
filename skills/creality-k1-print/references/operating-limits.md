# Supported scope and limits

- **Hardware:** original K1, nominal 220 × 220 × 250 mm bed/build area, 0.4 mm nozzle. K1 Max, K1C, CFS/multi-material systems and other firmware arrangements are not silently treated as the same printer.
- **Material:** PLA. The bridge bounds start temperatures conservatively for this workflow; do not reuse it for ABS/PETG/resin by changing only a label. Stock profiles do not establish spool calibration, moisture condition or final quality.
- **Maker preparation:** the printer's unmodified maker firmware/configuration is a trusted dependency. Preserve START_PRINT/END_PRINT and its normal homing/cleaning/leveling sequence. The automatic check only confirms the macros are present and START_PRINT contains the expected homing-call tokens. It does not prove that a Jinja branch will execute, inspect every nested macro or establish that END_PRINT has safe effects. Custom or untrusted firmware/macros require separate investigation and are outside the validated scope; this check cannot make a compromised printer safe.
- **Geometry:** preserve assembly transforms and uniform size. Unsupported/cyclic/external 3MF geometry must fail clearly. The model may still contain walls or details below the nozzle's printable resolution; inspect those rather than treating a closed mesh as a guarantee.
- **G-code:** ordinary Orca K1 PLA output, known numeric commands and a narrow named-macro set. Arc geometry must stay within the supported bounds. Unsupported units, planes and arc forms are rejected rather than approximated silently.
- **Preview:** actual deposited toolpaths, not an artistic render. A 3D display may sample paths to bound memory. Firmware macro motion is not expanded, and this is not a thermal, collision or support-removal simulation.
- **Approval:** the human approves the exact local artifacts. Hashes detect later changes; an approval reference is an operator record, not proof of human identity. Keep artifacts in a trusted local directory.
- **Physical steps:** leave the plate clear, load the intended PLA and inspect the first print. Removing a prior object, applying adhesive and removing supports are not automated by this software.
- **Connectivity:** Moonraker 0.10.0+ with API major 1 is required; the bridge checks the reported version before mutations. The checksum form field is supported in that server line. The computer must reach Moonraker. Do not expose it directly to the public internet. A separately configured private connection can provide remote reachability, but this package does not install a tunnel or a cloud account.
- **Scope of validation:** software tests and synthetic examples are reproducible. A confirmed print start on one original K1 does not validate every printer, profile, OS, filament or the final quality of a print.
